What To Do In One Paragraph

You are the tools agent. Your job is to communicate with the other agents (builder, reviewer, rust lane) using herdr commands, give each one a short written order exactly like the herd-boaz-dispatch.html pattern, wait for their replies, read them back, score them, and report. Do not write code yourself unless the order says so. Prove every claim with screenshots, build logs, and file paths.

Step 2 — Prompt Each Agent (Copy / Paste)

Same shape as the herd file: ORDER + working directory + exact proof expected + no-code rule for reviewers. Replace the session dir and lane per agent.

Builder order (does the work, shows proof)

herdr agent prompt e-climb --text "ORDER: boaz-prove your lane. BOAZ_SESSION_DIR=sessions-e-climb. Steps: herdr doctor, kill stale, fresh npm run build (0 errors), tsc --noEmit clean, launch with --disable-gpu, screenshot loaded control + editor + dark theme, record MP4 tour (load agenda, select song, change background, project), report back file paths + build log tail. No code edits this round unless build is red."

Reviewer order (scores, never edits code)

herdr agent prompt e-food --text "ORDER: boaz-verify vs perez-sheet.html. BOAZ_SESSION_DIR=sessions-e-food. Score each surface 0-10, append table to wt-electron/DOGFOOD.md under boaz-verify heading, prompt e-climb with re-score request. Reviewer never edits code. Report back scores + DOGFOOD.md path."

Rust lane order (same pattern, cargo)

herdr agent prompt r-climb --text "ORDER: boaz-prove Rust lane. BOAZ_SESSION_DIR=sessions-r-climb. Steps: cargo build -p perez-rs green, launch target/debug/perez-rs, screenshot full-width strip + VP buttons + live row, report back binary path + build tail + png paths."

Step 3 — Read Replies Back

herdr agent read e-climb
herdr agent read e-food
herdr agent read r-climb

If an agent is still working, wait and re-read. Do not mark complete while anyone is still working. Still-working replies become a follow-up update, not a silent drop.

Reply with the same blocks the herd file uses, so a human can publish it as-is:

  2. E-climb result: session dir, build status, suite count, png/mp4 paths.
  3. E-food result: session dir, per-surface table, DOGFOOD.md path.
  4. Orders issued: paste the exact herdr agent prompt ... lines you sent.

Rules Of Engagement

  • Talk through herdr agent prompt and herdr agent read only. No side channels.
  • One order per agent per round. Short orders beat long ones.
  • Reviewers score, builders prove. Reviewer never edits code.
  • Every claim needs a path: png, mp4, md table, or log tail.
  • Still-working is a valid status — report it, then follow up.
  • Park open questions in HERD-INBOX.md, not in chat.
